# Porsche 944 Engine Swap Knowledge Base

An open, source-traceable technical knowledge base for Porsche 944/951 engine swaps.

## Purpose

This project consolidates fragmented forum threads, vendor documentation, workshop data,
builder measurements, photographs, CAD work, and completed-build experience into a maintainable
technical reference.

The project began with the VW/Audi 07K swap, then expanded to compare the most credible,
well-developed engine alternatives for the Porsche 944 platform.

## Primary engine families

- Porsche 944 NA M44 — factory baseline
- Porsche 944 Turbo / 951 — factory performance baseline
- Porsche 968 3.0L
- VW/Audi 07K 2.5L I5
- VW/Audi 1.8T 20V
- Honda K-series, with K24 as the primary reference
- GM Ecotec
- GM aluminum LS-family V8
- Ford 2.3L EcoBoost

## Secondary / footnote candidates

2JZ, RB-series, VR6, Toyota 1UZ, Ford Coyote, Buick 3800, and Chevrolet 4.3 V6 are retained as
documented secondary candidates. They are not initially included in the main comparison matrix
unless new evidence materially improves their suitability or swap support.

## Core principles

1. Preserve provenance.
2. Separate verified data from estimates, vendor claims, builder reports, and speculation.
3. Record superseded information instead of silently deleting it.
4. Prefer actual measured swap-ready configurations over ambiguous internet engine-weight figures.
5. Preserve useful failed approaches when they explain later engineering decisions.
6. Remove forum chatter that adds no technical value.
7. Keep the public documentation useful to a builder who did not read the original threads.
