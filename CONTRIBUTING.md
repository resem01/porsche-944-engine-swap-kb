# Contributing

Contributions should improve technical accuracy, traceability, or practical build usefulness.

## Useful contributions

- measured dimensions with clearly identified datums
- actual scale weights with an exact list of attached components
- part numbers
- photographs documenting fitment
- wiring or ECU integration information
- CAD files or drawings
- documented failures and corrective revisions
- current vendor or kit changes
- links to significant completed builds
- corrections supported by stronger evidence

## Source requirements

Whenever possible include:
- source URL or document title
- author / builder / manufacturer
- date
- vehicle and engine configuration
- measurement method or relevant context
- whether the information was physically verified

Do not copy large portions of copyrighted forum posts or articles. Summarize technical content and
link to the original source.

See `docs/methodology/evidence-and-provenance.md`.
