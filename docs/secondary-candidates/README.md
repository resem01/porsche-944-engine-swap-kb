# Secondary Engine Candidates

These engines are intentionally retained as footnotes so useful historical work is not lost, but they are not part of
the primary matrix at project launch.

| Engine family | Why it comes up | Why it is secondary for now |
|---|---|---|
| Toyota 2JZ | Huge power capability, familiar swap engine | Long/heavy package and no mature 944-specific conversion ecosystem identified |
| Nissan RB-series | Inline-six performance heritage | Length, scarcity/cost and limited 944-specific support |
| Volkswagen VR6 | Compact cylinder-bank layout and VW availability | Height/length and limited proven 944 packaging |
| Toyota 1UZ | Aluminum DOHC V8, inexpensive historical donors | Wide DOHC package and little current 944-specific hardware |
| Ford Coyote | Modern high-output V8 | Very wide DOHC heads; documented 944 discussion describes extremely tight service clearance |
| Buick 3800 | Compact, durable and inexpensive V6 | Aging donor base and weak current 944-specific support |
| Chevrolet 4.3 V6 | Compact displacement-rich V6 family | Limited modern swap ecosystem compared with LS/07K alternatives |

These are **not rejected engines**. They remain searchable research subjects. Promotion into the primary comparison
requires stronger 944-specific evidence, a meaningful completed-build record, improved parts/adapter support, or a
compelling packaging/performance case.

The Nissan VK56 is treated separately as a formal feasibility study because its increasing swap popularity makes it
likely to recur as a proposed 944 powerplant.
