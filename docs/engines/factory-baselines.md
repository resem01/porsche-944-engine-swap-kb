# Factory Porsche Baselines

These engines are not all swap candidates in the same sense as the alternatives. They define the chassis' original
packaging, mass, thermal load and drivetrain context.

## 1985 944 NA — project baseline

North American 1985 reference:
- 2,479 cc naturally aspirated SOHC inline four
- aluminum block architecture
- 143 hp @ 5,500 rpm
- 137 lb-ft @ 3,000 rpm [S001]

A dry-engine weight of **166 kg / 366 lb** is repeatedly quoted from the Porsche workshop manual, but the current baseline
source is a secondary transcription and is therefore marked for primary-source verification [S002].

A later builder comparison puts a fully dressed NA engine with manifolds/accessories/clutch/bellhousing near **400 lb** [S009].
That number is more useful for swap comparison, but the project should reproduce the measurement on the actual 1985 engine.

## 1987 944 Turbo / 951 — project performance chassis

The early 951 uses the turbocharged 2.5L M44 family. US references list approximately **217 hp and 243 lb-ft** for the
standard early Turbo [S003].

The project's 1987 951 race-car chassis is valuable for:
- Turbo engine-bay geometry
- factory high-output cooling architecture
- stronger transaxle/drivetrain context
- track-oriented oiling/cooling comparisons
- measurement of differences from the early 1985 NA chassis

A verified, configuration-defined engine weight is still required.

## 968 3.0L — Porsche-native upper baseline

Porsche lists the 968's 3.0L four-cylinder at **240 PS and 305 Nm**; US references list **236 hp and 225 lb-ft** [S004][S005].
Factory-service-manual-derived data gives **172 kg / 379 lb dry** [S006].

The 968 therefore demonstrates that a large increase in naturally aspirated output is possible within essentially the
same transaxle-family packaging envelope without an enormous dry-weight penalty.
