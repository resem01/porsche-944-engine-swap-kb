# GM Ecotec Swap

## Baseline status

A GM Ecotec 944 is not theoretical. A detailed first-hand build on the Megasquirt support forum documents a completed,
street-driven turbocharged **L61 2.2L** installation [S017].

The September 2026 sweep did not locate a current commercial 944-specific Ecotec kit. The value of the Ecotec branch therefore
remains its proven one-off engineering architecture rather than vendor support.

## Documented 944 installation

The builder's engine package included [S017]:
- Chevrolet Ecotec L61 2.2L
- Wiseco pistons
- Eagle H-beam rods
- balance-shaft delete
- custom oil pan
- ported head / upgraded valvetrain
- LNF intake manifold adapted to the port-injected head
- BorgWarner EFR 7670 turbo
- Accusump oil accumulator

Drivetrain:
- Exedy lightweight steel flywheel
- SPEC Stage 3+ clutch using a Cavalier pressure plate and 944 NA clutch disc
- QuickTime Ecotec-to-T56 bellhousing
- custom T56-bellhousing-to-944-torque-tube adapter
- 2005+ Mustang slave cylinder
- factory 944 torque tube
- 944 Turbo S AOR transaxle
- S2 3.875 ring and pinion
- Turbo S LSD
- transmission cooler
- upgraded CVs/axles

The builder reported **415 whp at 20 psi** before the MS3X conversion and later returned to approximately the same boost/timing
level on MS3X [S017].

## Why this build matters

It demonstrates a generalizable architecture:
1. use an existing RWD Ecotec bellhousing,
2. adapt that bellhousing to the Porsche torque tube,
3. retain the Porsche rear transaxle,
4. solve the oil pan and engine mounts as chassis-specific fabrication.

That architecture is useful even if no commercial kit exists.

## LNF as a comparison engine

For a modern Ecotec comparison, the direct-injected turbo **LNF 2.0L** remains important. Published GM-derived specifications list
**260 hp / 260 lb-ft** [S018].

Advantages:
- factory turbo engineering
- aluminum block
- longitudinal RWD production precedent (Solstice/Sky)
- strong aftermarket

Disadvantages versus the documented L61 build:
- direct injection
- more complex ECU/fuel control
- no identified current 944 kit
- swap-ready weight still unverified

## Failure / durability context

The documented L61 builder specifically noted concern about high cylinder pressure in the open-deck L61 block and originally
limited boost while using a weaker transaxle. That is builder experience, not a universal Ecotec limit, but it is useful context
when comparing L61 and later Ecotec variants [S017].

## Current maturity assessment

**Maturity: Limited but physically proven.**

The Ecotec should remain in the primary comparison because a high-power 944 installation exists and the bellhousing architecture
is technically instructive. It should not be described as having current kit support.
