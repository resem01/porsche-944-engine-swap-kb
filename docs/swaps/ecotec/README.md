# GM Ecotec Swap

## Baseline status

A GM Ecotec 944 is not theoretical. A detailed first-hand build published on the Megasquirt support forum documents a
running turbocharged **L61 2.2L** installation [S017]. The project therefore treats Ecotec as a proven historical
installation architecture even though a current 944-specific commercial kit has not been identified.

## Documented 944 installation

The builder's configuration included:
- Chevrolet Ecotec L61 2.2L
- custom oil pan
- turbocharged engine
- QuickTime Ecotec-to-T56 bellhousing
- custom adapter from the T56 bellhousing to the Porsche torque tube
- factory 944 torque tube
- 944 Turbo S AOR transaxle with S2 ring and pinion
- custom clutch combination

The builder reported **415 whp at 20 psi** before later ECU changes and described the car as primarily street driven [S017].

That build is particularly useful because it demonstrates a workable torque-tube interface strategy independent of a
mass-produced kit.

## LNF as a comparison engine

For a modern Ecotec comparison, the turbocharged direct-injected **LNF 2.0L** is important. Published GM-derived
specifications list **260 hp / 260 lb-ft** [S018]. It also existed in longitudinal RWD applications such as the
Pontiac Solstice GXP and Saturn Sky Red Line, which makes it conceptually attractive for a 944.

However, direct injection and modern control requirements make the LNF electronically more complex than the L61 build
documented above.

## Strengths

- aluminum four-cylinder architecture
- strong turbo capability
- longitudinal-production precedent for LNF
- proven high-power 944 example
- possible use of existing GM bellhousing architecture as an intermediate adapter path

## Weaknesses / open items

- no current comprehensive 944 conversion kit found
- actual 944-ready weight remains unverified
- sump/crossmember geometry needs documentation
- accessory/HVAC integration is undocumented
- LNF direct-injection control may complicate standalone ECU choices

## Current maturity assessment

**Maturity: Limited, but physically proven.**
