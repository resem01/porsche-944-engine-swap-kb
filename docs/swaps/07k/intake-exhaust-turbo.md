# 07K Intake, Exhaust, Turbo, and Throttle Packaging

## Stock intake manifold conflict

The stock transverse 07K intake manifold was repeatedly test-fitted and found unsuitable for a normal 944 installation with the factory brake booster.

Primary conflicts:
- brake booster
- throttle-body location
- hood envelope depending configuration

Removing the brake booster created enough room for test fitting, but this was not considered an acceptable basis for the production conversion.

## Custom intake development

The production intake was designed specifically around:
- stock hood clearance
- factory vacuum brake-booster clearance
- longitudinal throttle-body location
- stock 07K intake gasket
- stock 07K fuel-rail compatibility
- cable-throttle bracket provision

Tooling began in early 2019 after several alternative manifolds were rejected for size or orientation.

## Current intake

Boost Brothers currently sells a cast aluminum manifold that:
- reverses the throttle body for longitudinal installation
- uses a large plenum
- provides six threaded vacuum ports
- includes throttle-cable bracket, hardware, and gaskets

## Throttle-body options

Historical thread options included:
- stock 07K electronic throttle body
- 1996-1998 VR6 cable throttle body
- larger electronic Porsche throttle bodies for custom ECU strategies

The cable-driven VR6 strategy became important because it allows:
- stock-style pedal/cable operation
- simpler ECU requirements
- no DBW pedal installation

The current Boost Brothers Haltech Elite 750 package is explicitly configured around a **VR6 cable throttle**, because that ECU package does not support DBW in the offered configuration.

## Turbo packaging

The 07K's shorter fore-aft package leaves useful room on the passenger/exhaust side.

Historical turbo development included:
- SPA TMW17 cast manifold
- Garrett G25-660 reverse-rotation turbo
- forward-facing exhaust options
- modified Lamborghini Gallardo 5.0 left-side exhaust manifold, p/n 07L253034A

The development team chose the reverse-rotation G25-660 partly to create a clean rearward exhaust path.

- [Page 20](https://rennlist.com/forums/944-turbo-and-turbo-s-forum/803341-vw-audi-07k-2-5l-20v-i5-swap-thread-20.html)

## Demonstrated output

The original turbo development car later exceeded 400 wheel horsepower during tuning. Subsequent thread discussion references approximately **450 whp** for Alan's turbo car.

A later Engine Swap Depot article documents the Boost Brothers test mule at:
- Garrett G25-660
- **350 hp**
- **320 lb-ft**
- lower-boost configuration

These figures likely refer to different tune states and should not be collapsed into one "official" output number.

## Fuel-injector packaging

The intake was designed to accept the stock 07K rail/injectors.

Later discussion covered Bosch EV14 injectors:
- long-nose injector geometry is preferred
- IE fuel rail is convenient but not mandatory
- some Porsche M97 injectors use a dual-cone spray pattern that may require different clocking

This is build/tune-specific information and should not be treated as a mandatory recipe.

## Status

**Intake packaging is mature. Turbo/exhaust packaging remains build-dependent.**

The current conversion preserves the factory brake booster and leaves passenger-side turbo room, but exhaust manifold, turbo, intercooler, and downpipe choices remain performance-target dependent.
