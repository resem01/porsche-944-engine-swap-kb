## Filtering rules used

Retained:
- dimensions
- part numbers
- fitment constraints
- design revisions
- failures
- installation procedure
- proven configurations
- completed-build results
- current-vs-superseded parts

Discarded:
- congratulatory posts
- repeated questions already resolved elsewhere
- unrelated suspension/brake projects unless they affect engine-swap fit
- shipping/payment chatter
- weather/social conversation
- speculative horsepower claims without technical context
- duplicate quotes that add no new information

## Remaining gaps

The thread is still a living source. Future review should specifically look for:
- exact torque values published by the development team
- complete early-vs-late chassis wiring differences
- verified before/after corner weights
- long-term mileage/reliability data from multiple completed cars
- standardized A/C implementation
- any final production instructions that were hosted off-thread and are still accessible
