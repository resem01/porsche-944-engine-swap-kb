# Honda K-Series Swap

## Baseline status

The project treats **K24** as the primary K-series reference because its displacement and torque are better matched to the
944 than a typical K20, while K20 cylinder heads and components remain relevant to high-performance variants.

A 2006 Acura TSX K24A2 provides a useful stock reference: **205 hp and 164 lb-ft** [S014].

The September 2026 sweep confirms that a turbo K24-powered 944 can run and drive while retaining the Porsche transaxle architecture,
but it also shows that the available 944-specific path remains immature [S016][S031].

## General RWD K-series support versus 944-specific support

KPower Industries provides mature RWD K-series hardware for several chassis and recommends the **K24A2 / equivalent K24A** as
the general starting point [S032].

However, KPower explicitly states that if a chassis is not listed in its catalog, it does not currently offer swap products for it.
The Porsche 944 is not a supported KPower chassis [S032].

Therefore:
- **general RWD K24 hardware is mature**
- **944-specific K24 hardware is not**

That distinction matters.

## Project K244 — documented 944 case study

The Drive began Project K244 in 2025 using an **untested overseas 944-specific kit** intended to retain the original Porsche
rear transaxle [S031].

The series is useful because it documents both physical fit and practical failure modes.

By September 2026 [S016]:
- the turbocharged K24 944 ran and moved under its own power,
- the engine required teardown and repair, including bent valves,
- gearbox/driveline interface work was required,
- clutch hydraulics required attention,
- wiring and turbo/intercooler packaging consumed significant effort,
- specialists ultimately helped finish the mechanical sorting,
- the car produced **nearly 300 hp at the wheels**.

The car proves feasibility, but the build does **not** validate the original kit as plug-and-play.

## Weight

A detailed 2024 builder weighing exercise on a K24A2 demonstrated why single-number K-engine weights are misleading.
Depending on installed components, reasonable K24 figures span roughly **240-320 lb** [S015].

A 944-ready K24 package should eventually be weighed with:
- intake/exhaust/turbo if used
- starter/alternator
- oil pan and RWD conversion hardware
- flywheel/clutch
- bellhousing/adapter
- mounts

## Why the K24 remains compelling

- aluminum four-cylinder architecture
- low mass relative to most V8s
- excellent engine availability
- huge parts/tuning ecosystem
- 200+ hp NA baseline
- strong turbo potential
- compact width

## Principal unresolved 944 questions

- repeatable bellhousing/torque-tube adapter geometry
- clutch stack height and hydraulic release geometry
- sump/subframe fit
- hood height and installed angle
- intake/brake-booster clearance
- A/C and accessory retention
- current source of a dependable 944-specific kit
- actual 944-ready installed weight
- whether a second independent build can reproduce the 2026 result without extensive re-engineering

## Current maturity assessment

**Maturity: Emerging / physically proven, commercially immature.**

The K24 remains a strong engineering candidate but should not be presented beside the 07K or 1.8T as if the installation
ecosystem is equally mature.
