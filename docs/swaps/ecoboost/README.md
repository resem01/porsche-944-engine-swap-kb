# Ford 2.3 EcoBoost Swap

## Baseline status

The longitudinal Mustang 2.3 EcoBoost remains technically attractive but **low-maturity** as a Porsche 944 swap.

The 2016 Rennlist feasibility thread established the obvious challenges—driveline interface, flywheel/starter/pilot-bearing
geometry, mounts, sump/crossmember clearance, wiring, and cooling [S022].

A September 2026 web sweep did **not** identify a completed 944/2.3 EcoBoost build or a commercial 944-specific conversion kit.
A 2025 community discussion still described the project as custom bellhousing/adapter engineering rather than a documented recipe [S037].

## Reference engine

Ford's North American 2015 Mustang specification:
- 2.3L turbocharged/direct-injected inline four
- 310 hp
- 320 lb-ft [S021]

The Mustang's factory longitudinal orientation is a genuine advantage compared with engines designed exclusively for transverse use.

## Why it remains interesting

- strong stock power/torque
- aluminum four-cylinder architecture
- factory RWD/longitudinal bellhousing ecosystem
- Ford control-pack/aftermarket knowledge
- compact cylinder count
- large modern performance aftermarket

## What remains unsolved for a 944

- verified engine envelope at 944 datums
- sump/rack/crossmember fit
- bellhousing-to-torque-tube adapter design
- flywheel/pilot-bearing stack
- mounts and installed engine angle
- brake-booster/steering clearance
- direct-injection/ECU integration
- A/C and accessory layout
- swap-ready weight
- evidence of a completed running car

## Current maturity assessment

**Maturity: Low / feasibility candidate within the primary comparison.**

EcoBoost stays in the matrix because the longitudinal donor architecture and output make it a rational engineering candidate.
It should not be mistaken for a currently supported swap.
