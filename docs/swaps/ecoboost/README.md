# Ford 2.3 EcoBoost Swap

## Baseline status

The longitudinal Mustang 2.3 EcoBoost is technically attractive but remains a low-maturity 944 swap candidate.
A 2016 Rennlist thread documents serious feasibility discussion, but the baseline research pass has not identified a
completed 944 installation or a mature commercial kit [S022].

## Reference engine

Ford's North American 2015 Mustang specification:
- 2.3L turbocharged/direct-injected inline four
- 310 hp
- 320 lb-ft [S021]

The longitudinal OEM installation is a conceptual advantage over engines developed only for transverse use.

## Why it deserves continued study

- strong stock output
- compact four-cylinder architecture in principle
- OEM longitudinal orientation
- factory control-pack precedent within the Ford ecosystem
- large modern performance aftermarket

## Principal unknowns

- actual engine width/height/length at common 944 datums
- sump-to-crossmember clearance
- bellhousing/torque-tube interface
- brake-booster and steering clearance
- 944-ready mass
- ECU/body-control requirements
- accessory and A/C retention
- whether any later builder actually completed the swap

## Current maturity assessment

**Maturity: Low.**

It remains in the primary comparison because it is a plausible modern longitudinal four-cylinder, not because a proven
944 solution currently exists.
