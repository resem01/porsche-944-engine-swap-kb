# Research Inbox

New web findings should be captured here or, preferably, as GitHub Issues before incorporation into the permanent documentation.

A research item should contain:
- URL
- source date
- author / vendor / builder
- engine family
- topic
- technical claim
- evidence class
- whether it confirms, contradicts, or supersedes existing information
- disposition: pending / accepted / rejected / superseded

The weekly web-monitoring task should surface only substantive new information.
